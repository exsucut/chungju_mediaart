## 0. Seedance 2.5 하드 제약

| 항목 | 값 |
|---|---|
| 클립 1회 최대 길이 | **30초** (4~30초, 1초 단위) |
| 해상도 | 1080p / 720p / 480p |
| image 레퍼런스 | **최대 30장** |
| character 레퍼런스 | **최대 30** |
| **product 레퍼런스** | **최대 1** ← 가장 빡빡한 슬롯 |
| **style 레퍼런스** | **최대 1** |
| video 레퍼런스 | 최대 10 (비용 증가) |
| audio 레퍼런스 | 최대 10, 개당 2~30초 |
| 멀티샷 | **한 생성에 최대 6샷**, 샷당 1~12초 |
| 레퍼런스 이미지 종횡비 | 0.4 ~ 2.5 (21:9 = 2.33 ✓ / 4:3 = 1.33 ✓) |
| 프롬프트 | 최대 40,000자 |

### 키프레임을 안 쓰기로 한 결정

Seedance 2.5는 키프레임과 레퍼런스가 **배타적**이다.

```
keyframes.start  prohibitedWith: image, video, character, product, style, color, effect
keyframes.end    prohibitedWith: (동일) · requiredWith: startFrame
```

키프레임을 쓰면 프랍·인물·스타일을 하나도 못 물린다. 이 작품은
**철당간 비례 · 철통 형태 · 대장장이 동일인 · 962년 고증**이 전부 프랍/인물 일관성에 걸려 있으므로
**전 클립 R모드(옴니레퍼런스)** 로 간다. 결과적으로:

- **종횡비는 파라미터로 명시**해야 한다 (첫 프레임이 잠가 주지 않음)
- 구도는 잠기지 않고 **레퍼런스로 유도**된다 — 프롬프트에 구도를 문자로 더 강하게 써야 한다
- 클립 간 연속성은 키프레임 체인이 아니라 **같은 배경 레퍼런스를 반복 주입**해서 만든다

### 운용 규칙
- **종횡비·길이·해상도는 프롬프트 본문에 쓰지 않는다.** 생성 파라미터로 넣는다.
- 에셋마다 **역할을 한 줄씩** 명시하고, 안 쓰는 에셋은 `【미사용 에셋】`에 번호를 하나씩 적는다.
- 시간 배분은 숫자 타임코드 대신 **단계(Stage)** 로 쓴다.
- 클립당 레퍼런스는 **3~5장**으로 묶는다. 30장 넣을 수 있다고 넣으면 서로 오염된다.

## 3. 레퍼런스 라이브러리

### 3-0. 프랍을 만드는 기준

옴니레퍼런스로 가면 **키프레임이 운반해 주던 몫이 사라진다.**
떨어져 있는 클립에 반복 등장하면서 형태가 흔들리면 안 되는 것은 **전부 프랍으로 만든다.**
반대로 뒷모습·실루엣으로만 읽히는 것은 만들지 않는다 — 슬롯 낭비이고 오염만 부른다.

| 대상 | 등장 | 판정 |
|---|---|---|
| 철당간 | S11·S12b·S17·S18·S19 | **필요** (기존 P0) |
| 철통 | S16L·S17 | **필요** P1 |
| 용두 | S18·S19 | **필요** P2 |
| 도가니(철 항아리) | B6R 3클립을 따로 생성 | **필요** P3 |
| 망치·모루 | B6L 12클립을 따로 생성 | **필요** P4 |
| 대장장이 | B6L 12클립 전부 동일인 | **필요** C1 |
| 마을 사람·아이들·농부 | 전부 뒷모습·실루엣, 얼굴 안 읽힘 | **불필요** ✗ |

### 3-1. 신규 제작 — 8장

| ID | 프랍 | 장수 | 쓰이는 곳 | 사양 |
|---|---|---|---|---|
| **P1** | 철통 단품 | 3 (정면·측면·사각) | B6L-13 · B7 | 속 빈 원통 관, 양끝 플랜지 테, 가운데 얕은 문양 띠. 검정 배경, 균일 조명 |

## 5. 트랜지션 설계

### 5-1. 클립 내부 — 멀티샷이 감당

| 구간 | 방식 |
|---|---|
| S1b→S2→S3 | 구름이 걷히며 땅이 드러남 → 부감이 그대로 수직 낙하로 가속 |
| S4a→S4b→S4c→S4d | 끊김 없는 전진, 길이 꺾이고 언덕으로 올라섰다 문으로 |
| S5→S6 | **카메라 완전 고정**, 하늘만 어두워짐 (밝기 폴다운) |
| S7→S8a | 빗줄기가 물벽으로 (라인 매치) |
| S8b→S8c | 물이 빠지며 잠긴 풍경 노출 |
| S9→S9b | 수면 관통 직후 화면·소리 동시 절단 |
| S11→S10 | 빛이 번지며 부유물이 어둠에서 떠오름 |
| S12→S12b | 산란이 최대에 달하고 문구 자리가 열림 |

### 5-2. 클립 간 연속성 — 배경 레퍼런스 반복 주입

키프레임 체인을 안 쓰므로 **같은 배경 이미지를 연속 클립에 반복 주입**하고,
프롬프트에 시작 상태를 문자로 명시한다.

| 이어지는 구간 | 공통 레퍼런스 | 프롬프트에 쓸 시작 상태 |
|---|---|---|
| B3A → B3B | B-절 | "마당은 이미 젖어 있고 하늘은 이미 어둡다" |
| B3B → B4A | B-절 | "물이 이미 기단까지 차 있다" |
| B4A → B4B | B-물속 | "수면선이 이미 화면 중앙에 있다" |
| B6R-1 → 2 → 3 | P3 도가니 | "항아리에 쇳물이 이미 (얕게/절반) 차 있다" |
| B8 → B9 | P0 + P2 | "당간은 이미 완성되어 서 있다" |

키프레임보다 연속성이 약하다. **접합부는 후반에서 디졸브·속도 매치로 보정**하는 걸 전제한다.

### 5-3. 후반 처리 — 생성으로 하지 않는다

| 구간 | 방식 |
|---|---|
| S1→B1 | 타이포 알파가 빛 입자로 흩어지며 구름으로 — 파티클 디졸브 |
| S9b | 완전 암전 2초 — 검정 프레임, 생성 불필요 |
| **S12b→S14** | ★ 아래 별도 항목 |
| S14→S15→S16 좌 | 타격음 비트에 맞춘 컷 편집 (13클립을 음악에 배열) |
| S15→S16 | 마지막 타격 후 0.5초 무음·암전 — 정적 한 박 |
| S18→S19 | 줌아웃 연속 |
| S19→END | 무대조명 ON + 페이드 — 영상에서 실물 철당간으로 시선 이양 |

### 5-4. ★ S12b → S14 전환 (S13 결번 대체)

원래 S13(수직 상승)이 담당하던 자리. 세 안을 검토했다.

**(a) 색 모프 + 재질 전환** — 물속 청록 빛줄기의 색상만 화로 주황으로 넘어가고,
물의 코스틱 무늬가 쇳물 표면 무늬로 재질이 바뀐다.
장점: 가장 매끄럽다. 단점: 공간 점프의 이유가 약하다.

**(b) 입자 관통** ← **권장**
「돛을 세워라」 문구가 금빛 입자로 흩어지고, **그 입자가 그대로 불똥이 되어** 화로에서 튄다.
문구가 물리적으로 불로 변환되는 구조라 인과가 선다.
장점: 문구·색·화면분할 세 전환을 한 동작에 묶는다. 단점: 입자 룩을 후반에서 맞춰야 한다.

**(c) 수직 상승 복원** — 카메라가 빛줄기를 따라 급상승해 수면을 뚫는데,

## 10. 연출 디렉션 원칙 — 프롬프트에 어떻게 박히는가

### 10-1. 일관성 — 세 가지 계약을 클립마다 문자로 반복한다

| 계약 | 내용 | 프롬프트 위치 |
|---|---|---|
| **카메라 계약** | 렌즈·높이·수평선·움직임 유무. "완전 고정"이면 세 단계 모두에 "카메라는 움직이지 않는다"를 쓴다 | 【일관성 유지】 |
| **광원 계약** | 색온도·키 방향·섀도우 리프트. 예: `2000K 앰버, 키 좌상, 섀도우 리프트 12%` | 【일관성 유지】 |
| **프랍 계약** | 형태·개수·위치. "철통은 30개, 양끝 테, 한 줄" — 개수를 반드시 숫자로 | 【피사체와 관계】 |

같은 배경·같은 프랍을 쓰는 클립은 **이 세 줄을 복사해서 붙인다.** 클립마다 다르게 쓰면 모델이 다르게 만든다.

### 10-2. 클립 내 디렉션 — 단계마다 상태 변화 하나, 끝 상태는 관찰 가능하게

- 한 단계에 **한 가지 주요 변화**만. "비가 오고 번개가 치고 물이 밀려온다"를 한 단계에 넣지 않는다.
- 끝 상태는 **눈으로 확인할 수 있는 문장**으로. "긴장감이 고조된다" ✗ → "마당 전체가 물에 잠겨 반사면이 된다" ✓
- 카메라 용어는 **대상 + 시작 위치 + 방향 + 도착 위치**로 푼다. "다이나믹하게" ✗ → "철통이 렌즈를 향해 다가오다 우측 탑 위로 멀어진다" ✓
- 감정·분위기는 **관찰 가능한 결과**로 바꾼다. "불길하게" ✗ → "먹구름의 그늘이 마당을 좌에서 우로 건너간다" ✓

### 10-3. 클립 간 연결 — 인수인계 문장

**앞 클립의 【끝 상태】를 뒤 클립의 【시작 상태】에 글자 그대로 옮겨 적는다.**
이게 키프레임 체인을 대신하는 유일한 장치다. 의역하면 끊긴다.

```
B3A 끝:  하늘은 먹구름으로 덮였고 마당의 마른 흙에 빗방울 자국이 찍혀 있다. 카메라는 움직이지 않았다.
B3B 시작: 하늘은 먹구름으로 덮였고 마당의 마른 흙에 빗방울 자국이 찍혀 있다. 카메라는 움직이지 않았다.
```
