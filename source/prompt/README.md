# 프롬프트

생성에 쓰는 프롬프트를 여기에 모은다. 흩어져 있으면 어느 판이 최신인지 흐려진다.

| 폴더 · 파일 | 무엇 |
|---|---|
| `iron_tower/` | **철당간 시퀀스 4클립** — 애니매틱 기반 Seedance 옴니레퍼런스 |
| `시댄스_클립설계_v1.md` | 클립 설계 원칙. 프랍 시트 규격(3절)이 여기 있다 |
| `가편_프롬프트_v1.md` | 가편 공통 블록과 레퍼런스 원칙 |
| `가편_히어로_프롬프트_v1.md` | 히어로 컷. 위 문서의 0-1절·1절을 물려 쓴다 |
| `S02_v2v_프롬프트_v1.md` | S02 video-to-video. Atlas 잡에서 본문을 그대로 참조한다 |

## 쓰는 법

프롬프트 본문은 **그대로 붙여넣는 것**을 전제로 썼다. 각 파일에서 구분선 아래가
본문이고, 그 위는 자산 번호·파라미터·읽은 내용 같은 작업 메모다. 메모는 붙여넣지
않는다.

화면비·길이·해상도는 프롬프트에 넣지 않는다. 페이지나 API 파라미터로 설정한다.

## 고치는 법

프롬프트를 고치면 파일을 고치고 커밋한다. 채팅에만 남은 판은 없는 판이다.
같은 클립의 다른 시도는 `_v2` 를 붙여 나란히 두되, 어느 쪽이 채택인지 표의
비고에 적는다.
