## 제출 순서

```
1. 클립 1  (01_대장간_붉은철통.md)
2. 클립 3  (03_회전결합_트랜지션.md)
3. 클립 2  (02_붉은에서_황금.md)   ← 1 과 3 의 경계 프레임이 나온 뒤에
4. 클립 4  (04_용두결합_엔딩.md)
```

**클립 2 는 순서상 두 번째이지만 세 번째로 만든다.** 첫·마지막 프레임 방식이라
클립 1 의 끝 프레임과 클립 3 의 첫 프레임이 먼저 있어야 한다. 프롬프트만으로는
두 컷의 구도가 정확히 맞지 않는다.

경계 프레임 추출:

```bash
ffmpeg -sseof -0.1 -i iron_Tower_21_9_1.mp4 -frames:v 1 clip1_last.png
ffmpeg -i iron_Tower_21_9_3.mp4 -frames:v 1 clip3_first.png
```

두 장의 화면비가 같아야 마지막 프레임이 늘어나지 않는다.

프롬프트에는 넣지 않는다. 페이지나 API 에서 설정할 것.

|---|---|---|

## 지켜야 하는 것

- **여백 존** — 캔버스 가로 34.8–41.6% 구간. 클립 3·4 에서 철당간과 전각이
  이 띠에 들어가지 않는다. 실제 설치에서 그 자리에 실물 국보가 서 있다.
- **철당간 비례** — 폭 : 높이 = 1 : 45. 굴뚝·드럼통처럼 굵으면 틀린다.
  `source/reference/철당간_기준/철당간_비례_사양.md` 참조.
- **깃발은 번(幡)** — 박공 머리, 그림 패널, 긴 띠 여러 가닥.
  기와집 지붕에 다는 삼각 페넌트가 아니다.
