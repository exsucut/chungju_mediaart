## 이후 처리
저장해 두시면 Magnific에 업로드해서 `style` 또는 `image` 레퍼런스로 물립니다.
지금 확정 컷을 레퍼런스로 물려 S5→S6 일관성을 잡은 것과 같은 방식입니다.

## 참고 — 핀터레스트 MCP 는 붙일 수 없음
- 공식 Pinterest MCP(2026-06 출시)는 **광고 캠페인 데이터 읽기 전용**. 보드/핀 조회 용도가 아님
- 서드파티 MCP 는 Pinterest API 앱 키가 필요하고, 현재 세션에서는 OAuth 승인을 진행할 수 없음
→ 파일로 넣어 주시는 방식이 가장 확실합니다
