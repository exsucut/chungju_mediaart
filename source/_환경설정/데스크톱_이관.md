## 데스크톱에서 할 일

### 1. 프로젝트 폴더 (자동)

같은 Apple 계정 로그인 → 시스템 설정 → Apple 계정 → iCloud →
**iCloud Drive → 데스크탑 및 문서 폴더** 켜기.

`Desktop/청주 국가유산 프로잭트` 가 내려옵니다. 161MB라 몇 분 걸립니다.
Finder에서 파일 옆 구름 아이콘이 사라지면 완료.

> 폴더가 보이는데 파일이 안 열리면 아직 다운로드 중입니다.
> 폴더 우클릭 → "지금 다운로드" 로 강제할 수 있습니다.

### 2. 저장소 clone

GitHub Desktop 설치 → GitHub 로그인 →
`File → Clone repository` → `exsucut/chungju_mediaart`
**경로는 기본값 `~/Documents/GitHub/` 그대로.** 빌드 스크립트가 이 경로를 씁니다.

### 3. git 설정 — 빼먹으면 푸시가 끊깁니다

```bash
git config --global credential.helper osxkeychain
git config --global http.postBuffer 524288000
git config --global http.version HTTP/1.1
git config --global http.lowSpeedLimit 0
git config --global http.lowSpeedTime 999999
```

노트북에서 이 설정 없이 푸시했다가 `The remote disconnected` 로 실패했습니다.
이미지가 많아 한 번에 올라가는 양이 커서 기본 버퍼(1MB)로는 안 됩니다.

### 4. Seedance 프롬프트 스킬


## 빌드 스크립트가 어떻게 바뀌었나

두 스크립트 모두 **맥에서도 그대로 돕니다.** 갈라진 사본을 만들지 않았습니다.

1. **출력 폴더 자동 판별** (`build_web.py`)
   `STORYBOARD_OUT` 환경변수 → 스크립트가 속한 git 저장소 루트 → 예전 맥 경로, 순으로 찾습니다.
   이제 저장소 안에 `source/` 가 들어왔으므로 윈도우에서는 자동으로 저장소 루트가 잡힙니다.

2. **이미지 축소 `shrink()`**
   Pillow 우선, 없으면 `sips`, 둘 다 없으면 원본 복사.
   Pillow 의 quality 눈금이 sips 보다 빡빡해서 **+16 보정**을 넣었습니다
   (실측: sips 72 ≈ Pillow 88 — 같은 원본에서 파일 크기가 100% 일치).
   이 보정이 없으면 새로 만든 컷만 화질이 떨어져 기존 컷과 섞입니다.

3. **재빌드 판정을 mtime -> 내용 해시로 교체** (`build_web.py`)
   git 은 mtime 을 보존하지 않습니다. 그래서 clone 직후 첫 빌드에서 **83장이 통째로 재인코딩**되고,
   17MB 짜리 의미 없는 커밋이 생겼습니다 (이관 중 실제로 발생, 되돌림).
   이제 원본의 SHA-1 을 `.build_manifest.json` 에 적어 두고 내용이 바뀐 컷만 다시 굽습니다.
   이 파일은 저장소에 같이 커밋해야 다음 기계에서도 헛일을 안 합니다.
   재빌드 시간: 전체 약 40초 -> 바뀐 게 없으면 0.4초.
