S12b 합성 소재 — 맵 세트
==========================

부처/  Buddha_*      1000 x 1000
철당간/ Pole_*        750 x 1333

  *_basecolor.png        알베도. 조명 성분을 뺀 색
  *_basecolor_alpha.png  위에 알파를 입힌 판 — 바로 얹어 쓸 수 있다
  *_normal.png           탄젠트 스페이스 노말 (OpenGL, +Y up)
  *_roughness.png        거칠기. 밝을수록 거칠다
  *_metalness.png        금속성. 돌은 0, 철당간 샤프트만 값이 있다
  *_height_depth.png     하이트 = 뎁스. 밝을수록 가깝다(돌출)
  *_alpha.png            컷아웃 마스크

쓰는 법
  2.5D  — basecolor_alpha 를 얹고 normal 로 라이트를 따로 먹인다.
          height 를 디스플레이스/패럴랙스에 물리면 카메라가 움직일 때 입체가 산다.
  3D    — 같은 폴더의 GLB 에 이 맵들을 물리면 된다.

주의
  맵 추출기가 1MP 를 넘는 입력을 줄인다. 원본 컷아웃은 부처 2048x2048,
  철당간 1440x2560 이므로 맵이 원본보다 작다. 더 큰 맵이 필요하면
  업스케일하거나 원본을 나눠서 다시 뽑아야 한다.

  height 는 사진 한 장에서 추정한 값이라 실제 깊이가 아니다. 얕은 부조
  정도로 보고, 큰 깊이감은 레이어를 나눠서 잡는 편이 안전하다.
