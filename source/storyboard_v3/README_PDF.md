# 스토리보드 PDF 내보내기

한 씬 = 한 페이지, A4 가로. 고른 안이 그대로 나온다.

## 가장 빠른 길 — 보드에서 바로

보드 우하단 **「PDF 내보내기」**(주황 버튼)를 누르면 인쇄 대화상자가 뜬다.
대상을 **PDF로 저장**으로 고르면 끝이다. 스크립트를 돌릴 필요가 없다.

지금 화면에 고른 안, 맞춰 놓은 세로 위치, 켜 둔 좌우 반전이 그대로 반영된다.
페이지마다 캔버스 합성(좌·우 테두리 + 갭 + 꺾임선), 좌·우 실제 크롭,
바닥 1:1, 레이아웃·카메라·톤·설명이 들어간다.

인쇄 설정에서 **배경 그래픽(Background graphics)** 을 켜야 테두리 색이 나온다.
여백은 「기본」, 용지는 **A4 가로**.

그 아래 회색 **「선택 JSON」** 버튼은 다른 용도다 — 고른 내용을 `picks.json` 으로
내려받아 아래 스크립트에 넘기거나 저장소에 굳힐 때 쓴다.

## 스크립트로 뽑기 (일괄·자동화용)

**1. 보드에서 안을 고른다.** 각 컷의 「버전」 줄에서 쓸 안을 클릭한다.
선택은 브라우저에 파일 이름으로 저장되므로 새로고침해도 남는다.

**1-b. 「세로 위치」로 크롭 높이를 컷마다 맞춘다.** 슬라이더를 끌거나
`▲ 위를 더` / `아래를 더 ▼` 를 눌러 조절한다. 두 화면이 **즉시** 움직인다.

- 값이 **커질수록 이미지의 아래쪽**이 보인다. 우측 파사드에 바닥을 넣으려면 올린다.
- `자동` 은 그 이미지의 지면선을 분석해 **우측 파사드 높이의 78% 지점**에 오도록
  계산한 값이다. 지면선이 뚜렷하지 않은 컷(구름·물속·암전)에는 제안이 없다.
- `기본` 은 전체 기본값 0.62.
- 값이 옆에 표시되고, 손댄 컷은 **●** 가 붙는다. 이것도 브라우저에 남는다.

좌우는 **한 장에서 잘라내는 것이라 맞바꿈이 있다.** 우측에 바닥을 넣으려고 값을
올리면 좌측은 그만큼 위가 잘린다. 컷마다 어디를 살릴지 직접 정하는 게 이 기능의 목적이다.

**2. 우하단 「선택 내보내기」를 누른다.** `picks.json` 이 내려받아진다.

**3. PDF를 만든다.**

```bash
python source/storyboard_v3/export_pdf.py --picks ~/Downloads/picks.json
```

`picks.json` 을 `source/storyboard_v3/` 에 두면 경로를 생략해도 된다.
아예 없으면 각 컷의 **첫 버전(최신 A안)** 으로 만든다.

```bash
# 일부 컷만
python export_pdf.py --only S5,S14,S18 --out 검토본.pdf
```

## 페이지에 들어가는 것

| | 내용 |
|---|---|
| 머리 | 컷 번호 · 이름 · 막 · 타임코드 · 길이 · **선택한 버전 이름** |
| 큰 그림 | 캔버스 합성 5320×1600. 좌(빨강)·우(파랑) 스크린 테두리, 갭(노랑, 실물 철당간 자리), 파사드 꺾임선 |
| 아래 줄 | 좌측 스크린 1920×960 실제 크롭 · 우측 파사드 3200×1200 실제 크롭 · **바닥 1:1** |
| 캡션 | 그 컷에 적용된 **세로 위치 값** |
| 발 | 레이아웃 · 카메라 · 톤 · 다음으로 · 설명 |

큰 그림은 **플레이트를 실제로 캔버스에 얹은 결과**다. 보드에서 맞춘 세로 위치가
그대로 쓰이므로 보드에서 보는 것과 같고, 투사되는 것과도 같다.

## 세로 위치를 확정하기

마음에 들면 shots.json 에 구워 둔다. 그 뒤로는 보드 기본값이 되고,
브라우저를 지우거나 다른 사람이 열어도 같은 크롭이 나온다.

```bash
python export_pdf.py --picks picks.json --write-align
python build_web.py          # 보드 다시 만들기
```

## 필요한 것

- Python + Pillow
- Chrome 또는 Edge (PDF 변환에 쓴다. 설치 경로를 자동으로 찾는다)

## 후보 접기 / 확정안 올리기

각 컷의 버전 줄은 **접힌 상태**로 뜬다. 지금 고른 안 하나만 보인다.

- **「후보 N개 보기」** — 펼쳐서 전체 후보를 본다. 다시 누르면 접힌다.
- **「★ 픽스」** — 지금 보고 있는 안을 그 컷의 확정안으로 올린다.
  그 버튼이 맨 앞으로 가고 ★ 가 붙는다. 브라우저에 남는다.

확정안을 저장소에 굳히려면 내보낸 picks.json 을 넘긴다.

```bash
python export_pdf.py --picks picks.json --write-pick --write-align
python build_web.py
```

`--write-pick` 은 ★ 픽스한 안을 `shots.json` 의 맨 앞으로 올리고 라벨에 ★ 를 붙인다.
그 뒤로는 브라우저를 지우거나 다른 사람이 열어도 그 안이 기본으로 뜬다.
