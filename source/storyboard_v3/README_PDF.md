# 스토리보드 PDF 내보내기

한 씬 = 한 페이지, A4 가로. 고른 안이 그대로 나온다.

## 쓰는 법

**1. 보드에서 안을 고른다.** 각 컷의 「버전」 줄에서 쓸 안을 클릭한다.
선택은 브라우저에 파일 이름으로 저장되므로 새로고침해도 남는다.

**2. 우하단 「선택 내보내기」를 누른다.** `picks.json` 이 내려받아진다.

**3. PDF를 만든다.**

```bash
python source/storyboard_v3/export_pdf.py --picks ~/Downloads/picks.json
```

`picks.json` 을 `source/storyboard_v3/` 에 두면 경로를 생략해도 된다.
아예 없으면 각 컷의 **첫 버전(최신 A안)** 으로 만든다.

```bash
# 일부 컷만
python export_pdf.py --only S5,S14,S18 --out 검토본.pdf
```

## 페이지에 들어가는 것

| | 내용 |
|---|---|
| 머리 | 컷 번호 · 이름 · 막 · 타임코드 · 길이 · **선택한 버전 이름** |
| 큰 그림 | 캔버스 합성 5320×1600. 좌(빨강)·우(파랑) 스크린 테두리, 갭(노랑, 실물 철당간 자리), 파사드 꺾임선 |
| 아래 줄 | 좌측 스크린 1920×960 실제 크롭 · 우측 파사드 3200×1200 실제 크롭 · **바닥 1:1** |
| 발 | 레이아웃 · 카메라 · 톤 · 다음으로 · 설명 |

큰 그림은 **플레이트를 실제로 캔버스에 얹은 결과**다. 위 62% / 아래 38% 로 잘려 나간
뒤의 모습이라 보드에서 보는 것과 같고, 투사되는 것과도 같다.

## 필요한 것

- Python + Pillow
- Chrome 또는 Edge (PDF 변환에 쓴다. 설치 경로를 자동으로 찾는다)
