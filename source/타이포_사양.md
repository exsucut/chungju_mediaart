# 타이포그래피 사양

스토리보드 이미지의 글자는 **임시(얇은 고딕)** 입니다.
최종 합성 시 아래 사양으로 교체해 주세요.

## 방향
꿈속에서 말을 건네는 느낌 — 가늘게 흐르는 손글씨.
정자체 고딕/명조 아님. 붓의 흐름이 남아 있는 필기체.

레퍼런스: `reference/moodboard/` 의 흑백 캘리그래피 이미지
(어두운 배경 · 흰 가는 획 · 은은한 발광 · 아래 작은 영문 부제)

## 서체
- 1순위 **HS봄바람체 2.1** — 이미 이 맥에 설치돼 있음
  `~/Library/Fonts/HSBombaram2.1.ttf` / PostScript: `HSBombaram21`
- 대안: 나눔손글씨 붓, 나눔손글씨 갈맷글

## 적용 대상
| 샷 | 문구 |
|---|---|
| S1 좌 | 제오경 (위에 작게 第五景) |
| S1 우 | 염원 / 주성의 돛대 / 용두사지 철당간 · 962 |
| S12b 우 | 돛을 세워라 / ― 부처가 이르기를 |

## 처리
- 자간 넉넉하게, 획은 가늘게
- 흰색 + 아주 약한 외부 발광(글로우), 하드 섀도우 금지
- 배경 위에 얹을 때 뒤를 살짝 눌러 가독성 확보 (검정 20~30%)
- 등장은 획이 그려지듯 또는 입자에서 응결되듯, 퇴장은 입자로 흩어지듯

## 주의
화면 안 사물(간판·현판)에는 한글 금지 — 962년 배경이라 시대 오류.
관람객용 오버레이 텍스트만 한글 사용.
